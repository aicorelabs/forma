§ 02 — Foundation

Type System

Three typefaces, each with a single role. Cormorant Garamond for display drama. Syne for UI clarity. Syne Mono for data and labels.

§ 04 — Foundation

Motion Language

Motion should feel deliberate and fluid. One choreographed reveal outweighs a dozen scattered micro-interactions.

linear
